# WhatsFeather

**A native WhatsApp client for Linux.**

No browser, no WebView, no Electron.

[Roadmap](ROADMAP.md) · [Security](SECURITY.md)

</div>

## Status

**Planning stage.** No application implementation or runnable release exists yet.
Native rendering and lower resource use are goals, not measured results.

## Direction

- A familiar WhatsApp-style interface with deliberate usability improvements.
- Local-first history, stable scrolling and reliable message delivery.
- Planned stack: Qt Quick, Go, SQLite and [whatsmeow](https://github.com/tulir/whatsmeow).
- Linux desktop first; text messaging before media and advanced features.

## Disclaimer

Unofficial and not affiliated with, authorized by, or endorsed by WhatsApp or Meta.
Protocol changes and account restrictions are possible. Voice/video calls are not currently supported or promised.
